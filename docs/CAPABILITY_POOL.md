# 个人 Agent 墨水屏能力池

更新日期：2026-11-08（Asia/Shanghai）。

本文件汇总本对话已确认的方向，以及从终端产品、小智生态、通用服务端、Home Assistant、ESP32-S31 和 AI Passport 项目调研得到的候选能力。详细证据见[屏幕、固件与摄像头报告](research/2026-11-08-esp32-projects.md)、[服务端生态报告](research/2026-11-08-server-ecosystem.md)、[ESP32 与 Home Assistant 报告](research/2026-11-08-home-assistant-esp32.md)、[ESP32-S31 报告](research/2026-11-08-esp32-s31.md)和[AI Passport 报告](research/2026-11-08-ai-passport.md)。

各项能力与具体来源项目的对应关系见[能力与来源项目索引](CAPABILITY_SOURCES.md)。

**这是候选能力清单，不是开发承诺或首期实施计划。** 首期功能、完整验收标准、服务端技术栈和复用方案仍待逐项讨论。某能力被收录，不代表必须为它提前搭建全部底座。

本轮广泛调研已告一段落，当前进入逐项筛选。每项确认是否保留、是否首期实现；具体结论与边界记录在[范围决策记录](SCOPE_DECISIONS.md)，确认后同步更新下表。

筛选增加[源码复用与迁移成本复核](research/2026-11-08-reuse-review.md)：先核对现有实现与剩余适配，已有且低成本的能力按用户要求纳入首期；有参考但对接量仍需验证的，单列“首期复用验证”。

## 1. 已确认的讨论共识

1. 最有用的方向是语音问答、记录想法、整理知识；调用工具需要建立可扩展底座。
2. 首期交互方向采用统一聊天入口。用户接受以“记一下”等自然表达表明保存意图，快速记录可以说完即提交。
3. 知识整理按主题标签关联原始笔记，由服务端定时归纳并更新主题页。原始笔记独立保留，目录、标签生成方式和调度周期待定。
4. Agent 记忆由 Agent 自主管理；它与用户可浏览的 Obsidian 知识库分别维护。
5. 本轮能力收集已基本完成；当前逐项确认是否做、是否首期做，再明确保留能力与底座的最小范围。
6. 参考重点是产品能力与底座机制。尺寸、板型和固件差异不作为排除理由，适配或迁移由我们自主完成；借鉴能力与采用原项目框架分别决定。
7. 首期 ASR 与 TTS 以“快速、免费实现”为准；具体方案在选型时核对接入工作量、实际响应速度与免费可用范围。
8. 先核对现成实现与迁移成本，再逐项确定范围。已讨论的选择也须据此复核；已有且容易迁移时做首期最小版，不能默认按从零开发估算。

Obsidian 是已确认的用户知识库目的地。本机服务端、VPS 转发、SQLite、模型和语音服务选项来自历史纪要；这些是设计背景和候选路线，未在本次讨论中全部定案。

## 2. 状态说明

- **目标已确认**：用户认可方向；不表示该项全部细节或首期工作量已确定。
- **待选择**：参考项目展示了相关能力，或由其产生了候选场景，后续决定是否保留。
- **源码已有部分**：本地工程存在相关实现，完整业务闭环和实机体验仍需验证。
- **另需验证**：存在明确硬件、模型、运行时或网络前提。
- **首期做**：用户明确同意纳入首期；具体实现以记录中的最低可用边界为准。
- **后续做**：保留方向，首期不实现；是否需要预留接口另行判断。
- **不做**：当前项目范围内不保留；记录原因，后续可重新讨论。
- **首期复用验证**：有源码依据，首期先验证限定的最小适配；通过成本与效果门槛后启用，发现需明显扩建时重新讨论范围。

迁移位置使用端侧、服务端、电脑桥接或外部设备描述。WS／LOCAL／CAM／PR 来源编号见屏幕报告，XZ／SV 见服务端报告，HA 见 Home Assistant 报告，S31 见 ESP32-S31 报告，AP 见 AI Passport 报告，RF 见复用复核报告。部分候选是组合场景，其完整闭环尚未由参考项目证明。下表中的适配备注用于后续实施评估，不用于本轮提前排除能力。

## 5. 逐项筛选时填写

每次讨论一个场景，记录以下内容，再更新决定列：

1. 用户什么时候会用，当前做法哪里不方便。
2. 用户操作、设备反馈和完成结果是什么。
3. 最低可用边界，明确的验收例子。
4. 哪些现有能力可复用，适配工作落在端侧、服务端还是外部连接器。
5. 对底座的最小要求和实际代价；硬件或固件差异记为实施事项，不作为能力本身的排除理由。
6. 选择：首期核心／首期最小底座／后续扩展／排除，以及原因。

尚未决定的问题包括：知识库目录与自动修改边界、原音和原图留存、连续语音需求、离线记录与同步、主动提醒、常驻看板、视觉推理位置、外部 Agent、动态上下文、个人流程、家庭场景与 HA 接入、手机代联网与电脑桥接、USB 外设、设备小应用与外设扩展，以及框架复用和部署细节。
